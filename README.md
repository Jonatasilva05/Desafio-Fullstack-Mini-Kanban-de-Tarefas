# Desafio-Fullstack-Mini-Kanban-de-Tarefas

- O objetivo deste desafio é avaliar a sua capacidade de desenvolver uma aplicação
fullstack simples utilizando React no frontend e Go no backend. Você deverá implementar um
pequeno Kanban com três colunas fixas (A Fazer, Em Progresso e Concluídas) e documentar
o fluxo de uso do sistema em um diagrama (User Flow).
